# Audio

Звуковая база для Dead Space 14.
Всего: 1 037 файлов (`.ogg`, Vorbis, 44 100 Hz, пик −1.0 dBFS).

Пространственные звуки мира сведены в Mono (1 канал) для 3D-позиционирования OpenAL; музыка, эмбиент, оповещения и логи — в Stereo (2 канала).
