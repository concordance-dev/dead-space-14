# Shuttle

Конструкция, двигатели и шлюзы челнока USG Kellion.
Всего: 2 RSI, 73 состояния (32x32).

- [shuttle.rsi](shuttle.rsi) — 69 состояний: переборки и углы корпуса, двери (`door0`, `door1`, `doorc0`, `doorc1`), двигатели и сопла (`propulsion*`, `burst_*`, `heater*`, `router*`), аппарель (`platform`)
- [shuttle_old.rsi](shuttle_old.rsi) — 4 состояния: базовые блоки пола и стен (`block`, `corner`, `orange`, `floor`)
