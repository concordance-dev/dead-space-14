# Lighting

Потолочные светильники, аварийное освещение, прожекторы, фонари и ритуальные лампы.
Всего: 2 RSI, 99 состояний (32x32).

- [lighting.rsi](lighting.rsi) — 90 состояний: люминесцентные трубки (`tube`, `ltube`), лампы накаливания (`bulb`, `lbulb`), напольные светильники (`floor`), аварийные лампы, фонари, прожекторы (`floodlight*`) и культовые лампы Обелиска (`marker*`)
- [lighting_overlay.rsi](lighting_overlay.rsi) — 9 состояний: световые маски для трубок, ламп и полов в обычном, ночном и аварийном режимах
