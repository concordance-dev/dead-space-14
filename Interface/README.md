# Interface

Элементы клиентского интерфейса SS14 в голографическом стиле RIG.

## [DeadSpace/](DeadSpace/)

- `SlotBackground.png` — фон слота инвентаря (32×32).
- `slot_highlight.png` — подсветка активного слота (32×32).
- `blocked.png` — индикатор заблокированного слота (32×32).
- `window_bg.png` — базовый фон панелей и окон (64×64).
- `button_normal.png`, `button_hover.png`, `button_pressed.png` — состояния кнопок интерфейса (48×24).
- [cursors.rsi](DeadSpace/cursors.rsi) — курсоры указателя, прицела, стазиса и кинезиса (32×32, 4 состояния).
