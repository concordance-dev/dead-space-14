# Logo

Иконки лаунчера и логотип проекта (производные от графики [Environment/CEC/](../Environment/CEC/)).

## Состав

- `logo.png` — промышленный логотип CEC на прозрачном фоне.
- `logo_flat.png` — плоский вариант логотипа (512×512).
- `icon.ico` — мультиразмерная иконка окна/приложения для Windows (16–256 px).
- `icon/` — отдельные PNG-иконки (`16x16`, `24x24`, `32x32`, `48x48`, `64x64`, `128x128`, `256x256`).
